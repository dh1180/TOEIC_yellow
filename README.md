# TOEIC Yellow (노랭이)

사용자가 제공한 `노랭이.apkg` + `노랭이_예문 기반.apkg`로 제작한 **Expo / React Native 영어 단어 학습 앱**입니다. 학습 카드, 오답 재출제, 간격 반복은 [HSK Plus Ultra](https://github.com/dh1180/HSK_Plus_Ultra)의 동작 규칙을 참고했습니다.

## 기능

- 빈출단어 1,241개 / 기초 837개 / 800점 2,033개 / 900점 990개, DAY 01~30 선택
- 신규 어휘보다 복습 기한을 지난 단어 우선 선택, 10·20·30개씩 학습
- 카드 뒤집기로 영단어 → 뜻 → 문맥 예문·한국어 의미를 공개
- **30분 → 3일 → 7일 → 21일 → 장기 기억** 간격 반복. 첫 학습에서 아는 단어는 장기 기억으로 분류(기억 인증은 아님)
- `알고 있음` / `다시 학습` 선택, 오답은 현재 세션 끝에 재출제
- 중단된 학습 이어하기, 검색·필터, 학습 통계
- 운영체제의 영어 TTS, 로컬 저장, 백업 내보내기·복원·초기화
- 원본/자체 작성/자동 문맥 초안의 **출처·검수 수준 표시**

**주의:** 자동 문맥 예문 2,728개는 실제 사용을 보여 주도록 만든 **초안**이며 일부 문장은 어색하거나 잘못되었을 수 있습니다. 한국어 칸에는 전체 문장의 번역이 아니라 어휘의 핵심 뜻을 표시합니다. 앱은 검수 전 자동 문맥 예문과 다른 카드의 원본 예문 재연결 후보를 기본으로 감추며, 사용자가 원할 때만 펼쳐서 볼 수 있습니다. **5,101개 전수의 영어·한국어 뜻 대조, 전수 전문 감수, 상용 콘텐츠 검수를 마쳤다고 주장하지 않습니다.** 외부 전문 감수 및 사용자 피드백은 계속 필요합니다.

원본 단어에서 의심되는 영어 관용구·약어·표기 오류는 **원본 표제어를 임의 변경하지 않고** `data/word-suspects.csv`에 따로 기록했습니다. 기존 학습 기록을 파괴하지 않기 위해 Anki note ID는 유지합니다.

검수 원장: `data/content-review-queue.csv` (전체 비원본 3,863개). QA 추가분: `data/qa-editorial-overrides.json` (각 단어 ID, 단어, 뜻, 예문, 생성 방식, 검수 사유). 자동 점검 결과: `data/content-audit.json`. 가이드: [`CONTENT_QA.md`](CONTENT_QA.md).

## 실행

**Node.js 24** (Expo SDK 58)에서:

```bash
npm install
npx expo start
```

실행 후 `a` Android, `i` iOS(macOS), `w` Web, 또는 Expo Go QR코드로 테스트합니다. 웹용 빌드는 아래 명령으로 검증할 수 있습니다.

```bash
npm test
python3 scripts/audit_content.py --check
npx expo export --platform web
```

GitHub Actions는 데이터·복습·백업 회귀 테스트, 독립적인 콘텐츠 무결성 검사, Expo 웹 번들 생성을 실행합니다. **웹 번들 생성 성공은 실기기 Android/iOS 기능 확인과 다릅니다.**

## 콘텐츠 재생성

원본 APKG의 `collection.anki21b`를 풀려면 `zstd` 명령이나 `zstandard` 패키지가 필요합니다. 규칙 기반 문맥 초안의 재생성에는 `textblob==0.19.0`이 필요하지만, `npm test`와 `audit_content.py`에서는 필요하지 않습니다.

```bash
python3 scripts/import_anki.py '노랭이.apkg' '노랭이_예문 기반.apkg'
python3 -m pip install -r requirements-content.txt
python3 scripts/curate_examples.py
python3 scripts/apply_qa_overrides.py  # ID별 직접 작성/재연결 643개 + 표제어 교정 재적용
python3 scripts/audit_content.py --write
npm test
```

`import_anki.py`만 실행하면 기존 단어 파일을 **임시 인용 문장으로 덮어쓰므로 반드시** `curate_examples.py` 다음에 `apply_qa_overrides.py`까지 차례대로 실행해 원본 자료와 이번 QA 추가분을 재적용한 후 결과를 검증하세요. 모든 생성 결과는 검수와 커밋 리뷰를 거쳐 병합해야 합니다.

## 학습 기록 및 개인정보

학습 기록은 기기의 AsyncStorage에만 저장합니다. 별도의 계정·광고·분석·서버는 없습니다. 백업 파일에는 단어별 학습 이력이 포함되므로 안전한 위치에 보관하세요. 음성은 운영체제 TTS에 의존하므로 선택된 음성 엔진이 네트워크를 사용할 수 있습니다.

## 배포·저작권 주의

공개 저장소에 들어간 원본 Anki 단어·예문의 저작권 및 재배포 허가는 본 개발로 확보되는 것이 아닙니다. 상용·스토어 배포 전 원저작권자의 라이선스 확인, 콘텐츠 감수, Android/iOS 실기기·접근성·음성·백업 검증, 스토어 등록 정보 점검이 필요합니다. 원본 MP3 파일은 저장소에 포함하지 않았습니다.

## 배포 전 차단 정책

`npm run release:check`와 EAS production 프로필은 현재 의도적으로 실패합니다. 전수 독립 언어 감수, 원본 데이터 사용 허가, Android/iOS 실기기 테스트가 끝나기 전에는 상용 배포가 완료된 것으로 취급하지 않습니다. 로컬 개발 및 Expo 웹 번들은 계속 테스트할 수 있습니다.
